# Contributing

Keep the scope to the portable portfolio application. Use synthetic examples and an isolated environment. Run the backend tests, frontend checks and source audit described in the README. Model-dependent tests require separately authorized private bundles and a private pytest basetemp for corruption fixtures; missing models are skips, not passing inference.

Do not include datasets, individual research records, private QA output, model payloads, credentials or the original Git history in contributions. Do not retrain or change frozen thresholds/contracts as a serving fix. Preserve applicable dependency notices and dataset attribution. A project software license has not been selected; do not assume a permissive license grant.
